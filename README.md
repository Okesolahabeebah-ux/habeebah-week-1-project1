# Week 2 - Responsive Intern Learning Dashboard
## Project Description
responsive intern learning dashboard built with HTML5 and CSS Flexbox to track weekly coursework progress, lessons learned, and future learning goals.
## What Was Practiced
-Semantic HTML structure and organization
-External CSS styling and typography layout
-Flexbox for alignment and responsive design components
-Media queries for mobile and desktop viewporta
-Git branching strategies and Github synchronization
## How to Open and Run
1. Clone or download the respository to your local machine.
2. Open the project folder in Visual Studio Code.
3. Use the **Live Server** extension to open dashboard.html in your web browser, or double-click the file to view it locally.
